Rules.
  1. MainForm: Maximized. Left: sidebar Panel 220 px (Dock Left, --side). Right: header Panel 56 px (Dock Top, white, bottom border), status Panel 26 px (Dock Bottom), content Panel (Dock Fill, --surface, Padding 20).
  2. Each screen is a UserControl hosted in the content Panel. It is created once and cached, so its state survives navigation and locking [ASSUMPTION; replaces MDI]. The header shows the screen title and the quick-search box (Ctrl+K).
  3. Sidebar items are flat Buttons (FlatAppearance.BorderSize = 0, TextAlign MiddleLeft, glyph Label + text). Hover = --side-hover. Active = --side-active + 3 px left bar #60A5FA + white text. A group opens its sub-items below it; only one group is open at a time. Shortcuts are shown muted on the right. Items without permission are hidden; an empty group is hidden.
  4. Trang chủ: greeting + 4 quick-action tiles (only the ones the user may use) [ASSUMPTION]. System warnings show here as a warning banner.
  5. Status bar: square 8 px dots: green = OK, red = degraded (text turns red semibold, tooltip explains). Refreshes every 60 s.
  6. User block at the bottom of the sidebar: initials tile, name, role, lock button (Ctrl+L).
