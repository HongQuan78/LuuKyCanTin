Rules (apply to every list screen).
  1. Toolbar row (FlowLayoutPanel, 8 px gaps, 16 px below): search InputFrame 300 px with a search glyph, then filter ComboBoxes whose label is inline ("Loại: Tất cả"), then a spacer, then secondary buttons, then one primary button last (the main action of the screen).
  2. Search: accent-insensitive ("nguyen van" finds "NGUYỄN VĂN"), 300 ms debounce, no Search button. Filters apply on change. On open the Trạng thái filter defaults to "Đang quản lý" [ASSUMPTION].
  3. The grid lives in a CardPanel (white, 1 px --border). DataGridView: BorderStyle None, EnableHeadersVisualStyles = false, header 38 px --subtle / #475569 semibold 9pt, rows 38 px, CellBorderStyle SingleHorizontal, GridColor #EEF2F6, selection --accent-soft with --text foreground, RowHeadersVisible = false, FullRowSelect, ReadOnly. The name column is semibold and the only Fill column.
  4. Status cells: a coloured square + text, drawn in CellPainting (green = Đang quản lý, red = Đã chuyển trại / Đã chấp hành xong án). Positive money is green semibold, zero plain. Money right-aligned "#,##0" vi-VN.
  5. Card footer: result count left, keyboard hints right (--muted). Row actions that are less frequent (Chuyển loại…, Xuất Excel) live in the row context menu.
  6. Read-only access (DM.Xem without DM.Them/DM.Sua): the write buttons are disabled; Enter opens the dialog read-only. No delete for detainees.

Rules (apply to every edit dialog).
  1. FixedDialog, CenterParent, width 560. Anatomy: title bar · dlg-head (17px semibold title + muted subtitle; on Sửa the title is the record's name and a tag shows its category) · body (TableLayoutPanel, 2 columns, 16 px gap, 14 px rows, padding 20) · footer band (--subtle) with buttons right-aligned, primary last; a secondary record action may sit on the far left.
  2. Labels above inputs (12px semibold #475569); required fields end with " *". Long fields (Họ và tên) span both columns.
  3. Read-only values (Loại on Sửa, Trạng thái, Ngày ra, Số dư lưu ký) are InputFrames with --subtle background: readable, copyable, not disabled-grey.
  4. Validation on Lưu: the field's InputFrame turns red (2 px --danger) and a red message with an error glyph appears under it; focus moves to the first invalid field; the dialog stays open. Server errors ("Mã số đã tồn tại") map to the same field. This replaces ErrorProvider icons.
  5. Concurrency conflict (rowversion): MessageBox "Dữ liệu đã được người khác thay đổi. Vui lòng tải lại." then reload [ASSUMPTION on wording].
